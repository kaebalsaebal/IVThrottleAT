# Third-party component

This build statically links MinHook v1.3.4, revision `c3fcafdc10146beb5919319d0683e44e3c30d537`.

Upstream: https://github.com/TsudaKageyu/minhook/tree/v1.3.4

Full copyright/license notices for MinHook and its included disassemblers are preserved in `third_party/minhook/LICENSE.txt`. A copy is also supplied in `bin/ThrottleAT-ThirdParty.txt` with the binary.

FusionFix source was consulted as a reference for native names and structure discovery. The CE059 implementation and x86 gate were written for this project and verified against the user's local executable. No FusionFix sources, ASI loader binary, GTAIV.exe, or Manual Gearbox components are redistributed.
